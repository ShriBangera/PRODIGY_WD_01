# Dolce Desserts - A mini project for Prodigy Infotech

Dolce Desserts is a web project that showcases a dessert-themed website. It is built using HTML, CSS, and optionally JavaScript for interactivity. The website presents desserts, offers visual appeal, and provides a platform for displaying products or content related to desserts.

## Project Overview

### The website includes:

* Home page with dessert showcase
* Responsive layout for different screen sizes
* Styled content using CSS in the assets folder
* Basic navigation between sections

## Technologies Used

* Frontend: HTML5, CSS3

* Optional: JavaScript for interactivity

* Assets: Images, fonts, and icons in the assets folder

## How to Run

1. Clone or download the repository:

    git clone https://github.com/ShriBangera/Dolce-Desserts.git


2. Open index.html in your web browser.

3. Explore the website and its dessert showcase.
